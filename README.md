# NearFind: Baguio Heritage Trail & Foot-Traffic Distributor

Decongesting urban tourism through gamified exploration and sustainable local vendor discovery.

---

## About The Project

NearFind is an interactive, mobile-first web application designed to solve urban overcrowding in Baguio City. By combining an RPG-style "Fog-of-War" exploration map with real-world economic incentives, NearFind gently pulls tourists away from congested central hubs (like Burnham Park and Session Road) and guides them toward off-center barangays and micro-artisans (like Guisad and Asin Road).

---

## Key Features

* Fog-of-War Exploration Map: Shrouds outlying artisanal sectors to incentivize exploration and clears permanently upon verified quest completion.
* Daily Commissions & Heritage Quests: Structured daily tasks guiding users to local weavers, woodcarvers, and independent cafes.
* EXIF-Verified Check-ins: Photo verification system to authenticate real-world visits to participating small businesses.
* Rewards Wallet & Vouchers: Earned experience points (EXP) unlock real merchant discounts and promo codes funded by public/private sector partnerships.
* Explorer Circle & Friends List: Compare Pathfinder ranks, view top pinned badges, and track friend activity across Baguio.
* Dual Revenue & B2B/B2G Model: Zero fees for micro-vendors; sustainable funding via LGU tourism grants and corporate-sponsored trails.

## How To Run Locally

Follow these steps to set up and run the project locally on your machine:

1. Prerequisites
   Ensure you have Node.js (v18 or higher) installed on your machine.

2. Clone the Repository
   ```bash
   git clone [https://github.com/YOUR-USERNAME/NearFind-Baguio.git](https://github.com/YOUR-USERNAME/NearFind-Baguio.git)
   cd NearFind-Baguio

   Install Dependencies

    npm install
    Start the Development Server
    npm run dev
